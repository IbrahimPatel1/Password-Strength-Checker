# Python Password Strength Checker

## Overview

I developed this Python password strength checker as part of my cybersecurity portfolio. The program checks passwords against common security requirements and gives a strength rating with suggestions for improvement.

## Features

- Checks password length
- Checks for uppercase and lowercase letters
- Checks for numbers and special characters
- Detects common passwords
- Calculates a security score out of 5
- Provides a strength rating
- Gives suggestions to improve password security
- Allows multiple passwords to be tested

## Skills Demonstrated

- Python programming
- Problem solving
- Conditional statements and loops
- Input validation
- Basic cybersecurity principles
- Attention to detail

## What I Learned

This project helped me improve my Python programming skills and understand how basic password security checks work. I also developed my problem-solving skills by designing the program to identify weaknesses and provide useful feedback.

## How to Run

1. Download `password_checker.py`
2. Open the file in VS Code or another Python editor
3. Run the program
4. Enter a test password when prompted
